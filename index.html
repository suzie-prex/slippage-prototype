Max Slippage Tolerance

Market order 슬리피지 허용 범위 설정 UI의 두 가지 변형입니다. 체크박스 활성화 → 값 설정 → % / USDT 모드 전환 흐름은 동일하며, 값을 설정하는 인터랙션 방식이 다릅니다.

V1

Dropdown Preset

미리 정의된 프리셋 목록에서 슬리피지 값을 선택하는 방식. Binance, Bybit 등 주요 거래소에서 사용하는 표준 패턴으로, 대부분의 유저가 익숙한 UI입니다.

Interaction Flow
  1. 1 체크박스 ON → 인라인 값 표시 (기본 0.02%)
  2. 2 값 영역 탭 → 드롭다운 오픈 (프리셋 목록 + By Percent / By Price pill toggle)
  3. 3 프리셋 선택 → 즉시 적용, 드롭다운 닫힘
  4. 4 Customize 탭 → 바텀시트에서 커스텀 값 직접 입력 (범위 제한 + Confirm)
장점
  • 원탭으로 빠른 설정 — 반복 트레이딩에 최적
  • 프리셋이 가이드 역할 — 초보자 접근성 높음
  • 프리셋 값은 입력 오류 원천 차단
단점
  • 최대 3단계 depth (드롭다운 → 토글 → 커스텀 시트)
  • 프리셋에 없는 값은 추가 스텝 필요
  • 드롭다운 내 pill toggle이 다소 복잡
Best for: 기본값을 주로 사용하고, 가끔 변경하는 일반적 트레이딩 시나리오. 초보 ~ 중급 유저가 많은 경우 적합.
V2

Text Field

인라인 텍스트 입력으로 슬리피지 값을 직접 설정하는 방식. 별도 바텀시트 없이 한 화면에서 완결되는 단순한 구조입니다.

Interaction Flow
  1. 1 체크박스 ON → 인풋 필드 노출 + 자동 포커스
  2. 2 값 직접 입력 → blur 시 유효범위 자동 클램프 (초과 시 에러 플래시)
  3. 3 유닛 버튼 (% ▾) 탭 → 드롭다운으로 By Percent ↔ By Price 전환
장점
  • 한 스텝으로 어떤 값이든 설정 가능
  • 인터랙션 depth가 얕음 (인풋 + 유닛 토글)
  • 세밀한 커스텀 값 설정에 유리
단점
  • 적절한 값을 유저가 직접 판단해야 함
  • 모바일 키보드가 화면의 절반을 차지
  • 오타, 범위 초과 등 입력 오류 가능성
Best for: 전략이 명확한 파워유저가 많고, 커스텀 값 설정 빈도가 높은 시나리오. 단순한 UI를 선호하는 경우 적합.
