Max Slippage Tolerance

Market order 슬리피지 허용 범위 설정 UI의 두 가지 변형입니다. 체크박스 활성화 → 값 설정 → % / USDT 모드 전환 흐름은 동일하며, 값을 설정하는 인터랙션 방식이 다릅니다.

V1

Text Field

인라인 텍스트 입력으로 슬리피지 값을 직접 설정하는 방식. 별도 바텀시트 없이 한 화면에서 완결되는 단순한 구조입니다.

Interaction Flow
  1. 1 체크박스 ON → 인풋 필드 노출 (기본 0.5%)
  2. 2 값 직접 입력 → blur 시 유효범위 자동 클램프 (초과 시 에러 플래시)
  3. 3 유닛 버튼 (% ▾) 탭 → 드롭다운으로 By Percent ↔ By Price 전환
  4. 4 Buy/Sell 탭 → 오더 프리뷰 바텀시트. 슬리피지 ON 시 Max slippage (% + USDT) · Max exec. price 표시
Value Input Rules
Percent기본 0.5% · 범위 0.1% – 5.0%
Price기본값 없음 (유저 직접 입력) · 범위 0.1 – 1,000 USDT
초과 처리Max 초과 시 즉시 max 값으로 자동 치환
장점
  • 한 스텝으로 어떤 값이든 설정 가능
  • 인터랙션 depth가 얕음 (인풋 + 유닛 토글)
  • 세밀한 커스텀 값 설정에 유리
단점
  • 유저가 직접 적정 값을 판단해야 함
  • 소수점 오타 리스크 (0.5 vs 5.0)
  • 가이드라인 없이 빈 필드는 진입장벽
Best for: 매 거래마다 슬리피지를 세밀하게 조절하는 고급 트레이더. 빠른 입력 + 정밀 제어가 중요한 경우 적합.
V2

Dropdown Preset

미리 정의된 프리셋 목록에서 슬리피지 값을 선택하는 방식. Binance, Bybit 등 주요 거래소에서 사용하는 표준 패턴으로, 대부분의 유저가 익숙한 UI입니다.

Interaction Flow
  1. 1 체크박스 ON → 인라인 값 표시 (기본 0.5%)
  2. 2 값 영역 탭 → 드롭다운 오픈 (프리셋 목록 + By Percent / By Price pill toggle)
  3. 3 프리셋 선택 → 즉시 적용, 드롭다운 닫힘
  4. 4 Customize 탭 → 바텀시트에서 커스텀 값 직접 입력 (범위 제한 + Confirm)
  5. 5 Buy/Sell 탭 → 오더 프리뷰 바텀시트. 슬리피지 ON 시 Max slippage (% + USDT) · Max exec. price 표시
Value Input Rules
Percent기본 0.5% · 범위 0.1% – 5.0% · 프리셋 0.1 · 0.3 · 0.5 · 1.0
Price기본값 없음 · 범위 0.1 – 1,000 USDT · 프리셋 1 · 5 · 10 · 20
초과 처리Max 초과 시 즉시 max 값으로 자동 치환
장점
  • 원탭으로 빠른 설정 — 반복 트레이딩에 최적
  • 프리셋이 가이드 역할 — 초보자 접근성 높음
  • 프리셋 값은 입력 오류 원천 차단
단점
  • 최대 3단계 depth (드롭다운 → 토글 → 커스텀 시트)
  • 프리셋에 없는 값은 추가 스텝 필요
  • 드롭다운 내 pill toggle이 다소 복잡
Best for: 기본값을 주로 사용하고, 가끔 변경하는 일반적 트레이딩 시나리오. 초보 ~ 중급 유저가 많은 경우 적합.
Design Proposal
% 기본값: empty → 0.5% pre-filled은 어떨까요?

PRD 기준은 empty이지만, 기본값을 미리 채워두면 아래 이점이 있을 것 같아 논의해보고 싶습니다.

PRD 현재
Empty
제안
0.5% Pre-filled
  • 즉시 주문 가능 — 체크박스 ON만으로 유효한 상태가 되어, 값을 입력하지 않아도 바로 주문할 수 있음
  • 판단 부담 감소 — 슬리피지 개념에 익숙하지 않은 유저가 적정값을 고민하지 않아도 됨
의견이 필요한 부분: 서비스 타겟이 프로 트레이더인 만큼, 본인이 설정하지 않은 기본값이 채워져 있는 것을 오히려 불편하게 느낄 수 있을지 궁금합니다. 프로 트레이더는 매 거래마다 슬리피지를 의도적으로 설정하는 경향이 있어, 시스템이 임의로 넣어둔 값보다 직접 입력하는 것을 선호할 수도 있습니다.
경쟁사: 바이낸스 — 기본값 없음 · 바이빗 — 기본값 있음 (pre-filled)
